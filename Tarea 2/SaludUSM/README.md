SaludUSM — Aplicación PHP

Ejecución local:
1. Copiar la carpeta SaludUSM dentro de htdocs de XAMPP.
2. Iniciar Apache y MySQL.
3. Importar el script SQL desde phpMyAdmin.
4. Configurar PHP/config/conexion.php con el nombre de la base,
   puerto, usuario y contraseña del entorno local.
5. Abrir http://localhost/SaludUSM/PHP/index.php
