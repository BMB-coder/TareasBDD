## Instrucciones de ejecucción
Para la tarea fue utilizado PostgreSQL como principal DBMS, por lo que es necesario descargarlo. Los scripts .sql son considerados bajo una base de datos ya creada llamada "salud_usm", la cual se debe crear dentro de pgAdmin4 manualmente o a través de psql. Con ello puede importar el DDL, DML y las respectivas consultas.
